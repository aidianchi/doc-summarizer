# 深度总结模板速查

> `实际原文标题`、`实际总结文件名` 是占位说明，生成文件时必须替换为真实文件名（不含 `.md`）。块链接必须写成 `[[实际原文标题#^paraXX]]`。
> 深度总结必须基于完整原文或保真可读化原文生成，禁止基于旧总结、Callout、MOC、概念卡或执行结果二次总结。

## 前置元数据
```yaml
---
title: "{主题}深度总结"
date: YYYY-MM-DD
tags:
  - 核心源主题   # 宽泛上位词，如：投资、心理学
  - 具体领域     # 收窄范围，如：价值投资、行为经济学
  - 核心概念     # 人名/方法名/理论名，如：巴菲特、复利（最多4个标签）
source: "[[实际原文标题]]"
---
```

```markdown
|------|------|------|

|------|----------|------|

- [[实际原文标题#^para01]]
```
